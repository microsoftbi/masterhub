# MasterHub 主数据管理系统 — UAT 测试用例

| 项目 | 内容 |
|---|---|
| 版本 | v1.0（覆盖 M1-M9 全部里程碑功能） |
| 测试环境 | 后端 http://localhost:3000（NestJS + SQLite），前端 http://localhost:5173（Vue3 + Element Plus） |
| 测试账号 | admin/admin123（系统管理员）、steward/steward123（数据管理员）、leader/leader123（数据域负责人） |
| 测试方式 | API（脚本 `scripts/uat-api.mjs` 自动执行）、浏览器（人工走查 + 截图存证） |
| 结果口径 | PASS / FAIL / BLOCKED，全部结果见 `uat-report.md` |
